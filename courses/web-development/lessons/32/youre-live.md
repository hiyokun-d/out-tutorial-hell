# You're Live!

You have a URL. Your portfolio is on the internet. That's real.

## What you built across this course

**HTML module** — you learned to structure web pages with semantic elements: headers, nav, sections, articles, forms, and footer. You built the skeleton of a real page.

**CSS module** — you learned the box model, flexbox, responsive design, colour systems, typography, and CSS variables. You styled a page that works on any screen size.

**JavaScript module** — you learned the DOM, event listeners, form validation, and dynamic page updates. You added behaviour to static HTML.

**Portfolio project** — you applied everything to build a real website from scratch, in VS Code, with your own content. You deployed it to the internet.

## What this means

Most people who try to learn web development watch tutorials for months and can't build anything. You built a real site and deployed it.

You know what a DOM is. You've written `addEventListener`. You've used flexbox. You understand why CSS variables exist. These aren't things you watched someone else do — you wrote the code.

## What's next

You have a foundation. Here's what you can build on it:

**Add more projects** — every project you build from here, add it to your portfolio. The portfolio itself is a project that grows.

**Learn Git** — version control lets you track changes, undo mistakes, and collaborate. GitHub is where most developer portfolios live and where employers look.

**JavaScript deeper** — arrays, objects, `fetch` (calling APIs), async/await. These unlock a huge range of things you can build.

**CSS deeper** — CSS Grid, animations, transitions, custom components.

**A framework** — once you're comfortable with vanilla JS, React or Svelte will feel logical instead of magical.

**A backend** — you've only done the front (what users see). The backend is the server, the database, the logic that runs behind the scenes.

None of that is urgent. You have a live website. Learn the next thing when you want to build something that needs it.

## One more thing

The URL you have — share it. Post it somewhere. Show someone. Not because you need validation, but because sending a link to something you built feels different to sending a link to a tutorial you watched.

That feeling is the thing this course was trying to get you to.

You're out of tutorial hell.
