# What is a Website?

A website is a set of files that a browser downloads from a server and displays on your screen. That's it. No magic.

When you go to `github.com`, your browser sends a request to GitHub's server. The server sends back a text file — HTML. Your browser reads that file and draws the page.

## The three languages of the web

Every website is built from three languages working together. Always these three, always in this order:

**HTML — Structure**
What content exists and what kind it is. Headings, paragraphs, images, links, buttons. HTML is the skeleton.

**CSS — Appearance**
How the content looks. Colours, fonts, spacing, layout, animations. CSS is the skin.

**JavaScript — Behaviour**
What the content does. Responding to clicks, fetching data, updating the page without reloading. JavaScript is the muscle.

Open any website. Press `F12`. Click "Elements". That's the HTML. Click "Styles". That's the CSS. Every website you've ever visited is built from these three files.

## Static vs dynamic

**Static website**: files sent to the browser as-is. HTML, CSS, JS. No database, no server logic. Your portfolio website will be static — and that's not a limitation, it's a feature. Static sites are fast, free to host, and dead simple to deploy.

**Dynamic website**: a server generates the HTML on request, usually pulling from a database. Twitter, Amazon, your banking app — dynamic. You'll get there eventually. For now, static is the right starting point.
