# Plan Your Portfolio

You've learned HTML, CSS, and JavaScript. Now you're going to build a real website — your portfolio — and deploy it so anyone in the world can visit it.

This isn't a tutorial you watch. You're writing the code yourself, in VS Code, saving it to your computer. At the end, you'll have a URL to share with anyone.

## What you're building

A portfolio website with five sections:

1. **Nav** — your name, links to sections
2. **Hero** — a punchy intro: "Hi, I'm [Name]. I build things for the web."
3. **About** — a few sentences about you
4. **Projects** — cards for 2–3 projects (real or in-progress, both are fine)
5. **Contact** — a simple form

It will be responsive (works on mobile), have a dark colour scheme, and a dark mode toggle.

## Your files

Create a folder on your desktop or Documents called `my-portfolio`. Inside it, create three files:

```
my-portfolio/
├── index.html
├── style.css
└── script.js
```

Open the `my-portfolio` folder in VS Code:
- File → Open Folder → select `my-portfolio`

Install the **Live Server** extension if you haven't already (lesson 2). Then right-click `index.html` and choose **Open with Live Server** — it opens in your browser and auto-refreshes on save.

## Decide your content

Before writing any code, settle these:

**Your name** — what you want displayed (can be first name, full name, a handle)

**Your tagline** — one sentence. Examples:
- "I build things for the web."
- "Learning to code, one project at a time."
- "Currently learning HTML, CSS, and JavaScript."

**Your about paragraph** — 2–3 sentences. Be honest:
- "I'm [name], a [job/student/career-changer] who started learning to code [recently/this year]. I went through the Getting Started course and learned C before web development. Now I'm building real things."

**Your projects** — 2 to 3. They don't need to be deployed yet. Use the projects from this course:
- "HTML Skeleton" — a structured web page built in HTML
- "Styled Portfolio" — a page with CSS, flexbox, and responsive design
- "Interactive Portfolio" — this portfolio, with dark mode and a contact form

**Your colour scheme** — pick one:
- Dark navy + red accent: `--primary: #1a1a2e; --accent: #e63946;`
- Dark slate + green: `--primary: #1b2838; --accent: #57c785;`
- Black + gold: `--primary: #0a0a0a; --accent: #f5a623;`

Write these down before the next lesson. Having the content ready means you can focus on the code.
