# Variables and strings

Python variables store values so you can reuse them later.

```python
name = "Maya"
print(name)
```

A string is text wrapped in quotes. You can combine strings with f-strings:

```python
name = "Maya"
print(f"Hello, {name}")
```

The `f` before the quote lets Python replace `{name}` with the variable value.
