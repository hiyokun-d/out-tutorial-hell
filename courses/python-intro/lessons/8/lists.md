# Lists

A list stores multiple values in order.

```python
languages = ["Python", "JavaScript", "C"]
print(languages[0])
```

List positions start at `0`, so `languages[0]` is `"Python"`.

You can loop over a list:

```python
for language in languages:
    print(language)
```

Lists are one of the most common data structures in everyday programming.
