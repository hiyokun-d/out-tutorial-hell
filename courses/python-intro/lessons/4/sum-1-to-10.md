# Sum 1 to 10

Use a `for` loop to add up every number from 1 to 10.

Print the result. It should be `55`.

**Requirements:**
- Use a `for` loop with `range()`
- Start with `total = 0`
- Add each number to `total` inside the loop
- Print `total` after the loop
