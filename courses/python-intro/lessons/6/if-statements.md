# If statements

An `if` statement lets a program choose what to do.

```python
score = 80

if score >= 70:
    print("Passed")
else:
    print("Try again")
```

Python uses indentation to decide what belongs inside the `if` block. The indented lines run only when that branch is chosen.

## Comparison operators

Common comparisons are:

- `==` equal to
- `!=` not equal to
- `>` greater than
- `<` less than
- `>=` greater than or equal to
- `<=` less than or equal to

Use `==` when comparing. Use `=` when assigning a value.
