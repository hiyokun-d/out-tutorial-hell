# Variables in C

C asks you to be explicit about the type of data a variable stores.

```c
int age = 25;
float price = 9.99;
char grade = 'A';
```

Common beginner types are:

- `int` for whole numbers
- `float` for decimal numbers
- `char` for a single character

Unlike Python or JavaScript, C does not guess as much for you. That strictness is part of why C is useful for learning how computers handle data.
