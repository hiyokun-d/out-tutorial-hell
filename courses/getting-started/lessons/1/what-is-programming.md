# What is Programming?

A computer is an extremely fast, extremely literal machine. It doesn't think. It doesn't guess. It does exactly — and only — what you tell it to do.

Programming is the act of writing those instructions.

## Why does code exist?

Every piece of software you use was written by someone. The app on your phone. The browser you're reading this in. The operating system managing your hardware. All of it is code — text files, written by humans, that tell a computer what to do.

Code exists because computers are powerful but dumb. They can execute billions of operations per second, but they need you to specify every single one.

## What does code actually look like?

This is a complete, working program:

```c
#include <stdio.h>

int main() {
    printf("Hello, world!\n");
    return 0;
}
```

That program prints one line of text. Seven lines of code to do something you could do by hand. But the same program could print it a million times, or do it based on user input, or do it after checking a hundred conditions first — all in under a second.

That's the trade: you learn the language, the computer does the grunt work.

## The programmer's mindset

The biggest shift beginners need to make is this: **the computer is not broken, and it's not wrong**. If your program doesn't behave the way you expected, you wrote something that wasn't quite right.

This sounds harsh. It's actually liberating. It means there's always a reason, always a cause, always a fix. You just have to find it.

## What you'll learn in this course

This course does not follow the typical path. Instead of jumping straight into web pages or tutorials, you'll:

1. **Understand how computers actually work** — memory, types, what "running" a program means
2. **Learn C first** — a language close enough to the machine that you'll see what's really happening
3. **Move to JavaScript** — and understand exactly why it's different from C, and what that means for you
4. **Build your first web pages** with HTML and CSS

By the end, you won't just be able to copy code. You'll understand why it's written the way it is.

## One last thing

Everyone who codes started exactly where you are. The difference between a beginner and an experienced programmer isn't talent. It's hours. Thousands of hours of writing things, breaking things, fixing things, and learning from all of it.

You're starting those hours now.
