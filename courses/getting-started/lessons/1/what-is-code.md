# What is Code?

Code is a set of instructions written for a computer to execute.

Computers are extremely fast and precise, but they have zero common sense. They do exactly what you tell them — nothing more, nothing less. Your job as a developer is to write instructions clearly enough that the machine can follow them without guessing.

## A simple mental model

Think of a recipe. A good recipe lists every step in order:

1. Boil 2 cups of water
2. Add pasta
3. Wait 8 minutes
4. Drain

A computer follows your code the same way — top to bottom, step by step, in exact order. Miss a step, write it wrong, or put it out of order, and the result is wrong.

## What code actually looks like

Here's HTML — the language that builds web pages:

```html
<h1>Hello, World!</h1>
<p>This is my first webpage.</p>
```

And here's JavaScript doing a simple calculation:

```javascript
let price = 100;
let discount = 20;
let total = price - discount;
```

Not magic. Just instructions written in a language the computer understands.

## Why learn this?

- Build websites, apps, and tools people actually use
- Automate repetitive tasks
- Understand the systems you interact with every day
- Think in a more structured, logical way

You don't need to be a math genius. You need curiosity, patience, and a willingness to break things and fix them.
