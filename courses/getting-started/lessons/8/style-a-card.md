# Style Your First Card

Cards are one of the most common UI patterns on the web — a box of content that stands out from the background. You're going to style one now.

The HTML structure is already there. Your job: write CSS inside the `<style>` block to make the `.card` look like a real card.

## Requirements

- Give `.card` a **background color**
- Give `.card` some **padding** (at least `1rem`)
- Give `.card` **rounded corners** with `border-radius`

Three properties. One card. Make it look good.
