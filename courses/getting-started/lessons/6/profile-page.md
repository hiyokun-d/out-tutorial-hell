# Build Your First Page

Time to write real HTML.

You're going to build a simple profile page — a page that introduces you to the web.

## What to build

- An `<h1>` with your name
- A `<p>` with one sentence about yourself
- A `<ul>` list with at least 3 things you want to learn

Write it, pass all the tests, earn your XP.
