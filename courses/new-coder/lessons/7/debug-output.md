# Use output to debug

Printing values is the simplest debugging tool.

When you are unsure what a variable contains, print it:

```javascript
let total = 5 + 8;
console.log(total);
```

You can also print labels so the output is easier to read:

```javascript
let total = 13;
console.log("total is", total);
```

In this lab, you will print a label and a value on the same line.
