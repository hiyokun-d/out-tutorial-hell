# Mini project: score message

Small programs combine the ideas you already practiced: variables, conditions, and output.

For this project, you will store a score and print a message based on it.

The logic is:

- If the score is at least `70`, print `Passed`
- Otherwise, print `Try again`

This is a small task, but it is a real program shape: input or stored data, a decision, then output.
