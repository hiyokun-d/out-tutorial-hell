# Style a simple card

A common UI pattern is a card: a grouped block with spacing, a border, and a background.

You can style one with inline CSS while learning:

```html
<div style="border: 1px solid black; padding: 16px;">
  Card content
</div>
```

Inline styles are not always the best long-term structure, but they are useful for learning what CSS properties do.
