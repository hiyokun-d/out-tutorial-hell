# Links and images

Web pages become useful when they connect to other pages and show media.

A link uses the `<a>` element:

```html
<a href="https://example.com">Visit example</a>
```

An image uses the `<img>` element:

```html
<img src="photo.jpg" alt="A clear description">
```

The `alt` text matters. It describes the image for screen readers and appears when the image cannot load.
